# 제품 사진 폴더

여기에 **직접 찍은 제품 사진**을 올리고, 구글 시트의 `photo` 칸에 파일 이름만 적으세요.

- 예: `dokdo-toner.jpg` 를 올렸다면 → photo 칸에 `dokdo-toner.jpg`
- 아이폰 사진(.heic)도 그대로 올려도 돼요. 세로로 찍은 사진도 자동으로 돌려서 맞춰요.
- 표지에는 가운데 부분이 가로로 잘려 들어가요. 제품을 화면 가운데에 두고 찍으면 좋아요.
- 올리는 방법: 이 폴더 화면에서 **Add file → Upload files** → 사진 끌어다 놓기 → **Commit changes**

사진 칸에는 파일 이름 대신 이미지 주소(https://...)나 구글 드라이브 공유 링크('링크가 있는 모든 사용자' 공개)를 적어도 돼요.
남이 찍은 사진·올리브영 상품 이미지는 쓰지 마세요 (제휴 프로그램이 홍보용으로 제공하는 이미지는 약관 확인 후 사용).
