# K뷰티 인스타·핀터레스트 자동 게시 봇

매일 한 번 **영어 카드뉴스**를 만들어 **인스타그램**(캐러셀)과 **핀터레스트**(핀)에 자동으로 올리고, 링크 페이지에 제휴 링크를 추가하는 봇이에요.
**정보가 주, 제품은 곁들이는 방향**이에요. 성분 101(피부·모발), 이번 주 K뷰티 TOP, 고민별 루틴, 오해 vs 사실, 성분 궁합, 계절 가이드, K뷰티 단어, 지난달 베스트셀러, 업계 동향, 연도별 변화, 서울 vs 해외, 제품 픽을 **주제별 한 달 목표 횟수**에 맞춰 골고루 올려요.
**주 3번(화·목·토)은 같은 카드뉴스를 음악 넣은 릴스로 먼저 올리고, 바로 이어서 카드뉴스도 올려요.**
올릴 제품도 **올리브영 글로벌 베스트셀러에서 매주 자동으로 모으고, 알리 공식 스토어에 있는지까지 확인**해요.
GitHub(무료)에서 돌아가서 컴퓨터를 켜둘 필요가 없어요.

## 자동으로 일어나는 일

**매주 월요일 아침 — 제품 찾기 (`Find bestsellers`)**
1. 올리브영 글로벌 베스트셀러(스킨케어·선케어·마스크팩, 성분 글용으로 헤어도)를 가져와요.
2. 평점 4.5 이상, 리뷰 30개 이상인 제품만 골라요.
3. 제품마다 **알리의 브랜드 공식 스토어에 같은 제품이 있는지** 확인해요.
4. 결과를 `data/auto_queue.csv`에 자동으로 추가해요. 알리에서 찾았는지 못 찾았는지도 함께 적혀요.

**매일 밤 — 게시 (`Daily post`)**
1. **매일 밤 10시쯤(한국 시간)** GitHub가 봇을 실행해요.
2. **이번 달 목표에서 가장 뒤처진 주제를 골라요** (아래 '주제별 게시 계획'). 그 주제에 올릴 게 없으면 다음 주제로 자동으로 넘어가요.
3. **영어 카드뉴스 5~8장과 캡션을 만들어요.** 제품 픽은 캡션 맨 위에, 제품 링크가 있는 정보 글은 캡션 안에 `#ad` 제휴 표시가 자동으로 들어가요.
4. **링크 페이지를 업데이트해요.** 인스타 프로필 링크로 걸어둘 페이지에 `No.12 → 구매 링크`가 추가돼요.
5. **인스타에 캐러셀로 게시해요.** 릴스 요일(화·목·토)에는 **같은 카드로 만든 세로 영상(음악 포함)을 릴스로 먼저 올리고, 이어서 캐러셀**을 올려요. 주제는 하루에 1개예요.
6. **핀터레스트용 세로 이미지(2:3)와 제품 페이지를 만들어 피드에 추가해요.** 핀터레스트가 24시간 안에 핀으로 올려요.

게시물마다 번호(No.12)가 붙고, 팔로워는 프로필 링크에서 그 번호를 찾아 구매해요.

- **순서:** 릴스 먼저 → 바로 이어서 같은 카드뉴스를 캐러셀로. 하루 2개일 때 릴스는 밤 게시에만 붙어요. 릴스 캡션에는 "카드 버전도 프로필에 있어요" 한 줄이 붙어요. 릴스가 실패해도 카드뉴스는 그대로 올라가요.

- 요일·장당 시간은 `config.toml [reels]`에서 바꿔요. 끄려면 `mode = "off"`.

- **성분 101 카드 (6~7장):** 표지 → 이게 뭐예요? → 효과 → 사용법(언제·순서·같이 쓰면 좋은 것) → 알아둘 점(오해와 사실) → **이 성분이 든 제품** → 저장 안내. 성분마다 색이 달라요.
- **'이 성분이 든 제품' 카드:** 매주 모으는 올리브영 글로벌 베스트셀러(`data/oy_catalog.json`)에서 **제품명에 그 성분이 들어간 인기 제품**(평점 4.5↑)을 최대 3개 골라 링크 페이지에 버튼으로 걸어요. 못 찾으면 조사해 둔 실제 제품을 링크 없이 보여주고, 이때는 `#ad`도 붙지 않아요. 알리 키가 생기면 알리 공식 스토어 링크도 자동으로 붙어요.
- **내용은 AI가 지어내지 않아요.** `content/` 폴더의 자료(피부 24개·모발 12개 성분, 비교 6개, 연도 15개)는 논문·피부과 자료·올리브영/화해 데이터·해외 뷰티 매체로 확인한 내용이고, 출처는 핀터레스트 상세 페이지 맨 아래에 나와요. 효능은 "도움을 줄 수 있어요" 수준으로만 쓰고, 치료·재생 같은 의학적 표현은 쓰지 않아요.
- **다 올리면?** 새 자료가 없으면 올린 지 120일이 지난 것부터 다시 올려요 (`repeat_after_days`). 그 사이엔 다른 정보 글이나 제품 픽으로 채워요. 남은 개수는 매 실행 요약에 나와요.
- **횟수 바꾸기:** `config.toml`의 `[series]`에서 `per_month`(한 달 횟수)를 고치면 돼요. 0이면 그 주제는 꺼져요. `[series]`를 통째로 지우면 예전처럼 `[schedule] weekly`의 요일별 순서로 돌아가요.
- **자료 추가하기:** `content/` 폴더의 `skin.toml`·`hair.toml`·`trends.toml`·`routines.toml`·`seasons.toml`·`words.toml`에서 블록 하나를 복사해 고치면 돼요 (영어로, 짧게. 단어 시리즈만 한글 사용). 오해 vs 사실·성분 궁합은 성분 자료에서 자동으로 만들어져요. 저에게 "성분 10개 더 조사해서 추가해줘"라고 해도 돼요.

## 내가 할 일: 없어도 돼요 (하고 싶을 때만)

설정이 끝나면 **제품 찾기부터 게시까지 전부 자동**이에요. 원할 때만 이렇게 손대면 돼요.
- **빼고 싶은 제품이 있으면** GitHub에서 `data/auto_queue.csv`를 열고 그 줄을 지워요 (연필 아이콘 → 줄 삭제 → Commit).
- **직접 고른 제품이나 써본 제품을 올리고 싶으면** 구글 시트에 적어요. **내 시트가 항상 자동 목록보다 먼저** 올라가요. 사진, 한줄평, 별점을 넣을 수 있는 것도 내 시트뿐이에요.
- **바로 새 제품을 찾고 싶으면** Actions 탭 → `Find bestsellers` → **Run workflow** 버튼을 눌러요.

`data/auto_queue.csv`의 `ali_check` 칸은 이런 뜻이에요.
- **found (official store) $12.90:** 알리 공식 스토어에서 찾았어요. 알리 링크와 사진, 올리브영 링크 둘 다 걸려요.
- **not found:** 알리 공식 스토어엔 없어요. 올리브영 링크만 걸려요.
- **not checked:** 알리 키가 아직 없어요. 키를 넣으면 다음 월요일에 다시 확인해요.

### 구글 시트에 직접 적을 때
구글 시트에는 브랜드, 제품명, 종류, 링크를 적어요.
- **알리 링크는 비워둬도 돼요.** 봇이 알리의 **브랜드 공식 스토어**에서 같은 제품을 자동으로 찾아서 알리 링크, 사진, 가격을 붙여요. 못 찾으면 올리브영 링크만 걸고 올려요.
- **이미 올린 줄은 알아서 건너뛰어요.**

### 링크는 두 개까지 걸 수 있어요
올리브영 글로벌이 **2026년 5월 29일부터 미국 배송을 중단**해서, 제품마다 링크를 두 개 걸어요. 링크 페이지에 버튼이 두 개 생기고, 캡션에도 안내가 들어가요.
- **AliExpress 버튼:** 미국 팔로워용이에요.
- **Olive Young Global 버튼:** 그 외 나라 팔로워용이에요.

| 시트에 적은 것 | 봇이 하는 일 |
|---|---|
| 올리브영 링크만 | 알리의 **브랜드 공식 스토어**에서 같은 제품을 자동으로 찾아요. 찾으면 알리 링크, 사진, 가격을 붙이고, 못 찾으면 올리브영 링크만 걸어요 |
| 올리브영 링크 + 알리 주소 | 둘 다 걸어요. 알리 주소는 제휴 링크로 자동 변환돼요 |
| 알리 주소만 | 알리 링크만 걸어요 (올리브영 제휴 가입 전에 쓰는 방법) |

**자동 찾기는 일부러 깐깐하게 만들었어요.** 판매자 이름에 **브랜드명과 "Official"이 모두** 있고 제품명도 대부분 맞을 때만 붙여요. 더 싸고 많이 팔린 상품이라도 공식 스토어가 아니면 무시해요 (가품 방지).
- **직접 넣은 주소가 우선이에요.** 자동으로 붙은 알리 상품이 이상하면 `aliexpress_link` 칸에 원하는 주소를 직접 넣으면 돼요.
- **자동 찾기를 끄려면** `config.toml`에서 `auto_find_aliexpress = false`로 바꾸면 돼요.
- **판매자 이름이 안 오는 경우:** 알리 API가 판매자 이름을 알려주지 않으면 공식 스토어를 확인할 수 없어서 자동 찾기를 하지 않아요. 그때는 알리 주소를 직접 넣어주세요.
- **알리 API 키가 필요해요.** 알리 자동 찾기와 알리 주소 변환은 8단계에서 키를 넣은 뒤부터 작동해요. 그전에는 올리브영 링크만으로 올라가요.

### 사진과 후기 넣는 법
- **사진:** 폰으로 찍은 제품 사진을 저장소의 `photos` 폴더에 올리고, 시트 `photo` 칸에 파일 이름(예: `dokdo.jpg`)만 적으면 돼요.
  - 아이폰 사진(.heic)도 그대로 돼요. 제품을 화면 가운데에 두고 찍어주세요.
  - 구글 드라이브에 올렸다면 공유를 "링크가 있는 모든 사용자"로 바꾸고 그 링크를 적어도 돼요.
- **평점·리뷰 수:** 상품 페이지에 보이는 숫자를 그대로 옮겨 적으면 "4.8 average · 12,345 reviews on Olive Young"처럼 출처와 함께 나가요.
- **리뷰 요약:** 리뷰를 몇 개 읽고 자주 나오는 이야기를 **내 말로** 요약해 적어요. 카드에는 "요약이며 직접 인용이 아님" 표시가 자동으로 들어가요.
- **내 후기:** 직접 써본 제품만 `my_comment`와 `my_rating`을 적어주세요.

> 💡 카드뉴스가 영어라서 **브랜드와 제품명은 영어로** 적어주세요. 한줄평·특징·순위를 한국어로 적었다면, AI 키(Gemini 무료 또는 Claude, 아래 참고)가 있을 때는 자동 번역되고 없을 때는 빠지고 올라가요.

## 처음 설정하기 (한 번만, 약 1시간)

### 1단계. GitHub 저장소 만들기
1. [github.com](https://github.com)에 가입하고 로그인해요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
3. 저장소 이름을 **`내GitHub아이디.github.io`**로 정해요 (예: 아이디가 `seoulskin`이면 `seoulskin.github.io`). **Public**을 선택하고 **Create repository**를 눌러요.
   - ⚠️ 이 이름이어야 링크 페이지 주소가 `https://seoulskin.github.io/`가 되고, **핀터레스트에서 "내 사이트" 인증**을 할 수 있어요. 다른 이름으로 만들면 핀터레스트 자동 게시가 안 돼요.
   - 무료 링크 페이지(GitHub Pages)를 쓰려면 Public이어야 해요. 비밀번호와 토큰은 따로 "Secrets"에 넣기 때문에 공개되지 않아요.
4. 압축을 푼 폴더 안의 **모든 파일과 폴더**를 저장소 페이지에 끌어다 놓고 **Commit changes**를 눌러요. 링크는 **uploading an existing file**이에요.
   - ⚠️ `.github` 폴더도 꼭 올려야 해요. 맥에서는 이 폴더가 숨겨져 있으니 Finder에서 `Cmd + Shift + .`을 누르면 보여요.

### 2단계. 링크 페이지 켜기 (GitHub Pages)
저장소에서 **Settings → Pages**로 가서 **Build and deployment → Source**를 **GitHub Actions**로 바꿔요.

### 3단계. 계정 이름 바꾸기
저장소에서 `config.toml`을 열고 연필 아이콘(✏️)을 눌러 아래 값을 바꾼 뒤 **Commit changes**를 눌러요.
```toml
handle = "내_인스타_아이디"
brand_name = "링크 페이지 제목"
tagline = "한 줄 소개 (영어)"
```

### 4단계. K뷰티 목록 (구글 시트) 연결
> 구글 드라이브에 **"K뷰티 게시 목록 (인스타 자동 게시 봇)"** 시트가 이미 있다면 1~2번은 건너뛰고 3번부터 하면 돼요.

1. 새 구글 시트를 만들고 **1행에 아래 한 줄을 그대로 붙여넣어요.**
   ```
   brand,product,category,oliveyoung_link,aliexpress_link,photo,rank,key_points,my_comment,my_rating,store_rating,review_count,review_highlights,hook,date
   ```
   붙여넣은 뒤 **데이터 → 텍스트를 열로 분할**을 하면 칸이 나뉘어요.
2. 2행부터 제품을 적어요. `#`로 시작하는 줄은 메모로 취급해서 건너뛰어요.
3. **파일 → 공유 → 웹에 게시**를 누르고, 해당 시트와 **쉼표로 구분된 값(.csv)**을 선택한 뒤 **게시**를 눌러요. 나온 주소를 복사해요.
4. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서
   - Name: `KBEAUTY_SHEET_CSV_URL`
   - Secret: 방금 복사한 주소

   를 넣고 저장해요.

> 구글 시트 대신 저장소의 `data/kbeauty_queue.csv`를 GitHub에서 직접 편집해도 돼요.
> 게시한 시트는 수정 후 반영까지 최대 5분쯤 걸려요.

### 5단계. 미리보기로 첫 실행 (인스타 연결 전에 해봐도 돼요)
1. 저장소 **Actions** 탭에서 워크플로 사용 안내가 나오면 **I understand... enable**을 눌러요.
2. 왼쪽 **Daily post → Run workflow**를 누르고 **"미리보기만"에 체크된 상태 그대로** 실행해요.
3. 1~2분 뒤 실행 기록을 열면 요약에 **캡션과 연결 점검 결과**가 나와요. 맨 아래 **Artifacts → preview-images**에서 카드 이미지 5장을 받아 확인하면 돼요.

### 6단계. 인스타그램 연결
1. **인스타 앱에서 프로페셔널 계정으로 전환해요.** 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → **크리에이터**를 선택해요.
2. [developers.facebook.com](https://developers.facebook.com)에 로그인해요 (페이스북 계정이 필요해요).
3. **내 앱 → 앱 만들기**를 누르고, 사용 사례에서 **"Instagram에서 메시지 및 콘텐츠 관리"**를 선택해 앱을 만들어요.
4. 앱 대시보드에서 **Instagram → Instagram 로그인을 통한 API 설정**으로 가서 **"액세스 토큰 생성" → 계정 추가**를 누르고 내 인스타로 로그인해 권한을 허용해요. 생성된 **토큰을 복사**해요.
   - 테스터 초대를 요구하면 **앱 역할 → 역할 → Instagram 테스터**에 내 계정을 추가해요. 그다음 인스타 웹에서 **설정 → 앱 및 웹사이트 → 테스터 초대**를 수락하면 돼요.
   - Meta 화면은 자주 바뀌어서 메뉴 이름이 조금 다를 수 있어요.
5. GitHub Secret에 **`IG_ACCESS_TOKEN`**이라는 이름으로 토큰을 넣어요.
6. 5단계 미리보기를 한 번 더 돌려서 연결 점검에 **"인스타: @내아이디 연결됨"**이 나오는지 확인해요.

### 7단계. 실전 첫 게시 + 프로필 링크 걸기
1. **Run workflow**에서 **"미리보기만" 체크를 해제**하고 실행해요. 잠시 뒤 인스타에 첫 게시물(No.1)이 올라가요.
2. 링크 페이지 주소 `https://내아이디.github.io/`를 **인스타 프로필의 웹사이트 링크**에 넣어요. (링크 추가는 핸드폰 인스타 앱에서만 돼요: 프로필 편집 → 링크 → 외부 링크 추가)
3. 이후로는 매일 자동으로 올라가요.

> 💡 첫 게시 전에 링크 페이지를 먼저 열고 싶으면(404가 뜰 때) **Run workflow**에서 "올릴 종류"를 **site**로 골라 실행하세요. 인스타에는 아무것도 올리지 않고 링크 페이지만 새로 올려요.

### 7-1단계. 핀터레스트 연결 (컴퓨터에서 해주세요)
핀터레스트는 API 없이 **RSS 피드 자동 게시**를 써요. 무료이고 심사도 없어요.
1. **비즈니스 계정 만들기:** 핀터레스트 계정을 만들거나 기존 계정을 비즈니스 계정으로 바꿔요 (설정 → 계정 관리 → 비즈니스 계정으로 전환). 무료예요.
2. **내 사이트 인증하기:**
   - **설정 → 소유권 확인(Claimed accounts) → 웹사이트 → 소유권 확인**으로 가서 주소에 `https://내아이디.github.io`를 넣어요.
   - **"HTML 태그 추가"**를 고르면 `<meta name="p:domain_verify" content="abc123..."/>` 같은 줄이 나와요. `content="..."` 안의 값만 복사해요.
   - GitHub의 `config.toml`에서 `[pinterest]`의 `domain_verify = ""` 따옴표 안에 붙여넣고 Commit해요.
   - Actions → `Daily post` → Run workflow를 **미리보기 체크 해제**로 한 번 실행해요. 링크 페이지에 인증 태그가 올라가요.
   - 핀터레스트로 돌아가 **확인(Verify)**을 눌러요.
3. **보드 만들기:** 예를 들어 "K-beauty Picks" 보드를 만들어요.
4. **RSS 피드 연결:**
   - **설정 → 핀 대량 생성(Bulk create Pins) → RSS 피드 자동 게시**로 가요.
   - 피드 주소에 `https://내아이디.github.io/feed.xml`을 넣고, 3번에서 만든 보드를 골라 저장해요.
   - 이후로는 새 게시물이 생길 때마다 핀터레스트가 **24시간 안에** 핀을 올려요.
   - 핀을 누르면 제품 페이지(`/p/번호.html`)로 가고, 거기에 AliExpress·올리브영 구매 버튼이 있어요.
   - 메뉴 이름은 핀터레스트 화면 변경에 따라 조금 다를 수 있어요.

### 8단계. 알리 제휴 승인이 나면 (알리 도구 + 알리 주소 K뷰티 모두 이때부터 작동)
AliExpress 포털 승인 후 [AliExpress Open Platform](https://openservice.aliexpress.com)에서 개발자로 등록하고 앱을 만들면 App Key와 App Secret이 나와요. Tracking ID는 제휴 포털에서 발급받아요. 세 값을 Secret으로 넣으면 다음 날부터 알리 도구가 번갈아 올라가요.

| Secret 이름 | 값 |
|---|---|
| `ALI_APP_KEY` | App Key |
| `ALI_APP_SECRET` | App Secret |
| `ALI_TRACKING_ID` | Tracking ID |

알리 도구는 이런 기준으로 골라요.
- **검색 대상:** 괄사, 아이스롤러, 실리콘 세안패드, 메이크업 스펀지, 두피 브러시처럼 **피부에 바르지 않는 비전자 도구**만 찾아요.
- **자동 제외:** 유명 브랜드명이 들어간 상품(가품 위험), 크림·세럼 같은 바르는 제품, 전기·LED 기기, 평점 90% 미만, 판매 200건 미만 상품은 빼요.

## 올리브영 제휴 프로그램 정리

올리브영에는 제휴 프로그램이 두 가지 있어요. 성격이 달라서 이 계정에는 글로벌 쪽이 맞아요.

| | 국내 **쇼핑 큐레이터** | **올리브영 글로벌** 제휴 |
|---|---|---|
| 대상 구매자 | 한국 올리브영 앱·온라인몰 고객 | 해외 고객 (글로벌몰) |
| 가입 | 올리브영 앱에서 약관 동의만 하면 바로 시작 (팔로워 조건 없음) | 글로벌몰 회원 + SNS 계정이면 가입 가능 |

## 매주 제품 찾기 (올리브영 글로벌 → 알리 확인)

- **어디서 가져오나요?** 올리브영 **글로벌** 사이트(global.oliveyoung.com)의 베스트셀러 목록이에요. 이 사이트의 robots.txt는 해당 경로(`/display`)의 수집을 허용해요. 봇은 매번 robots.txt를 다시 확인하고, 허용이 바뀌면 스스로 멈춰요. 국내 올리브영(oliveyoung.co.kr)은 자동 수집을 막아두어서 쓰지 않아요.
- **얼마나 자주, 얼마나 가져오나요?** 일주일에 한 번, 목록 3~6개를 요청 사이에 쉬어가며 가져와요.
- **가져오는 정보:** 브랜드, 영어 제품명, 순위, 평점, 리뷰 수예요. **올리브영 상품 이미지는 가져오지 않아요** (사용 허락이 없어서요). 카드에는 알리 공식 스토어 사진이나 디자인 표지가 들어가요.
- **알리 확인은 엄격하게 해요.** 판매자 이름에 **브랜드명과 "Official"이 모두** 있고 제품명도 대부분 맞을 때만 "found"로 적어요.
- **설정 바꾸기:** `config.toml`의 `[discover]`에서 목록 종류, 몇 위까지 볼지, 최소 평점·리뷰 수, 빼고 싶은 브랜드를 바꿀 수 있어요.
- **올리브영 글로벌 제휴에 가입했다면:** `[kbeauty]`의 `oliveyoung_link_template`을 내 제휴 링크 모양에 맞춰 바꿔요 (예: `"{url}&referral=내코드"`). 리워드 코드가 있으면 `oliveyoung_code`에 적으면 캡션과 페이지에 표시돼요.

## 선택 사항

**AI 카피 — Gemini 무료 (`GEMINI_API_KEY`) · 추천**
- **하는 일:** 표지 제목을 더 자연스럽게 다듬고, 한국어로 적은 한줄평·특징·순위를 영어로 번역해요.
- **발급:** [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에 구글 계정으로 로그인해서 **Create API key**를 누르고, 만든 키를 `GEMINI_API_KEY` Secret에 넣어요. 카드 등록은 필요 없어요.
- **비용:** 무료 한도로 충분해요 (하루 1번만 불러요).
- **참고:** 무료 버전은 구글이 입력 내용을 서비스 개선에 쓸 수 있어요. 봇이 보내는 건 제품명과 설명뿐이라 괜찮아요.
- **모델:** `config.toml`의 `gemini_model`(기본 `gemini-flash-latest`)을 쓰고, 안 되면 다른 Flash 모델로 자동으로 바꿔 시도해요.
- **오류가 나면:** 일시 오류(서버 혼잡·요청 한도·네트워크)일 때 **5초 → 1분 → 5분** 뒤에 다시 시도해요. 그래도 안 되면 **백업 AI**(`BACKUP_AI_KEY`, 기본 Groq 무료)로 넘어가요. 그것도 안 되면 내장 템플릿으로 게시해요. 게시는 절대 멈추지 않아요.
  - 키가 틀린 것처럼 다시 시도해도 소용없는 오류는 기다리지 않고 바로 다음 AI로 넘어가요.
  - 순서·간격은 `config.toml`의 `[copy]`에서 `ai_order`, `retry_delays`로 바꿀 수 있어요.

**백업 AI — Groq 무료 (`BACKUP_AI_KEY`)**
- **하는 일:** Gemini가 재시도 후에도 안 될 때 대신 카피를 써요.
- **발급:** [console.groq.com/keys](https://console.groq.com/keys)에 구글 계정으로 로그인해서 **Create API Key**를 누르고, 키를 `BACKUP_AI_KEY` Secret에 넣어요. 무료 한도는 하루 약 1,000번이라 충분해요.
- **다른 곳을 쓰고 싶다면:** OpenAI 호환 API(OpenRouter 등)는 `config.toml`의 `backup_ai_url`·`backup_ai_model`·`backup_ai_name`만 바꾸면 돼요.
- ⚠️ GitHub Models는 2026년 7월에 서비스가 종료돼서 백업으로 쓸 수 없어요.

**Claude AI 카피 (`ANTHROPIC_API_KEY`)** — Gemini 대신 쓰고 싶을 때 (두 키가 다 있으면 Claude 우선)
- **하는 일:** 표지 제목을 더 자연스럽게 다듬고, 한국어로 적은 한줄평·특징·순위를 영어로 번역해요.
- **발급:** [console.anthropic.com](https://console.anthropic.com)에서 API 키를 만들어 Secret에 넣으면 돼요.
- **비용:** 하루 1개 기준으로 한 달에 1달러도 안 들어요. 단, 처음에 최소 충전 금액이 있어요.
- **없어도 괜찮아요:** 내장 템플릿으로 문제없이 돌아가요.

**인스타 토큰 자동 연장 (`GH_PAT`)**
- **왜 필요해요:** 인스타 토큰은 60일마다 만료돼요. `Refresh Instagram token` 워크플로가 한 달에 두 번 연장하는데, 새 토큰을 Secret에 저장하려면 GitHub 토큰이 있어야 해요.
- **만드는 법:** GitHub 프로필 **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**으로 가요. 이 저장소만 선택하고 권한은 **Secrets: Read and write**로 줘요. 만든 토큰을 `GH_PAT` Secret에 넣어요.
- **안 넣는다면:** 50일마다 6단계를 다시 해서 토큰을 새로 넣어주세요.

## 자주 바꾸는 설정

- **주제별 횟수:** `config.toml`의 `[series]` (위 '주제별 게시 계획' 참고)
- **릴스:** `config.toml`의 `[reels]` (`mode` auto / manual / off, `days`, `seconds_per_slide`)
- **제품 픽 날의 번갈아 방식:** `config.toml`의 `mode` 값을 바꿔요.
  - `alternate`: 하루씩 번갈아 (기본)
  - `kbeauty_first`: K뷰티 우선
  - `tools_first`: 알리 우선
- **게시 시간:** `.github/workflows/daily-post.yml`의 `cron: "7 13 * * *"`를 바꿔요. UTC 기준이라 한국 시간에서 9시간을 빼면 돼요.
  - `7 13 * * *`: 한국 22:07 · 미국 동부 오전 9시 (기본)
  - `7 0 * * *`: 한국 09:07 · 미국 동부 저녁 8시
- **알리 조건:** `config.toml`의 `[aliexpress]`에서 최대 가격, 최소 평점, 최소 판매량, 찾을 도구 종류를 바꿀 수 있어요.
- **해시태그:** `config.toml`의 `[copy]`에서 바꿔요.

## 문제 해결

- **핀터레스트에 핀이 안 올라와요**
  - 사이트 인증(7-1단계)이 끝났는지 확인해주세요.
  - 저장소 이름이 `아이디.github.io`인지 확인해주세요.
  - 피드 주소 `https://아이디.github.io/feed.xml`이 브라우저에서 열리는지 확인해주세요.
  - 핀터레스트는 피드를 확인하는 데 최대 24시간이 걸려요.
- **`Find bestsellers`가 새 제품을 못 가져와요**
  - 실행 기록 요약에 이유가 나와요.
  - "robots.txt가 허용하지 않음"이면 사이트 정책이 바뀐 거라 봇이 스스로 멈춘 거예요.
  - "응답 형식이 바뀌었어요"면 사이트가 개편된 거라 봇 수정이 필요해요.

- **`Get Pages site failed` 오류**
  - 2단계(Pages → Source: GitHub Actions)를 했는지 확인해주세요.
  - 저장소가 Public인지도 확인해주세요.
- **인스타 게시 실패 `code 190`**
  - 토큰이 만료됐거나 잘못됐어요.
  - 6단계에서 새 토큰을 만들어 `IG_ACCESS_TOKEN`을 다시 넣어주세요.
- **인스타 게시 실패 (이미지 관련)**
  - 링크 페이지 배포가 늦어서 생길 때가 있어요.
  - 다음 날 같은 상품으로 자동 재시도하고, 바로 올리고 싶으면 Run workflow를 눌러요.
- **"오늘 올릴 게 없어요"**
  - 제품 목록과 정보 글 자료가 모두 소진됐어요. 시트에 제품을 추가하거나 `content/`에 자료를 추가해주세요.
  - 알리 키가 없으면 K뷰티만 올라가요.
- **성분 글에 제품 링크가 없어요**
  - `Find bestsellers`가 한 번도 안 돌아서 `data/oy_catalog.json`이 없거나, 베스트셀러 중 제품명에 그 성분이 든 제품이 없어서예요. 이럴 땐 예시 제품만 링크 없이 나가요.
- **매일 실행이 멈췄어요**
  - GitHub는 60일 동안 저장소 활동이 없으면 예약 실행을 꺼요.
  - Actions 탭에서 워크플로를 다시 켜주세요. 평소에는 매일 게시 기록이 저장돼서 꺼지지 않아요.
- **같은 날 두 번 실행했는데 안 올라가요**
  - 하루 1개로 제한해뒀어요. 스팸 판정을 막기 위해서예요.
- **"브랜드·제품명은 영어로" 경고**
  - 해당 줄을 영어로 고치거나 AI 키를 넣어주세요.

## 꼭 지켜주세요

- **제휴 표시(#ad)는 지우지 마세요.** 미국 FTC 같은 해외 규정과 한국 공정위 모두 광고 표시를 요구해요.
- **안 써본 제품에 `my_comment`를 쓰지 마세요.** 한줄평은 "내가 직접 써봤다"는 뜻으로 올라가요. 안 써봤다면 비워두면 돼요. 그러면 루틴 설명 장으로 대체돼요.
- **올리브영 사이트를 자동 수집하지 않아요.** 사이트가 자동 접근을 막고 있어서 제품은 사람이 골라요.
- **알리 K뷰티는 공식 스토어만 넣어주세요.** 가품 화장품을 추천하면 팔로워 피부에도, 계정 신뢰에도 문제가 생겨요.
- **사진은 내가 찍은 것만 넣어주세요.** 올리브영·브랜드의 상품 사진을 가져다 쓰면 저작권 문제가 생길 수 있어요. 제휴 프로그램이 홍보용으로 제공하는 이미지는 약관을 확인한 뒤 쓰면 돼요. 알리 도구는 제휴 API가 제공하는 상품 이미지를 써요. 사진이 없으면 디자인 표지로 나가요.
- **리뷰 글을 그대로 복사하지 마세요.** 다른 사람의 리뷰 문장은 작성자의 저작물이에요. 평점 숫자는 그대로, 내용은 내 말로 요약해주세요.
- **없는 후기나 평점을 만들어 넣지 마세요.** 가짜 후기는 미국 FTC와 한국 공정위 모두 제재 대상이에요.
- **알리 가격은 게시 시점 기준이에요.** 카드에도 "가격은 바뀔 수 있고 관세가 붙을 수 있다"고 적혀 나가요.
- **제휴 수익은 각 프로그램의 정산 기준과 세금 신고 대상이에요.**

```
tests/                   ← 가짜 API로 전체 흐름을 검사하는 테스트
```
